# Permanent real-user language regression lessons

Candidate47 preserves these general families. Named examples illustrate the
failure class; they must never become phrase-specific production exceptions.
Use grammatical/semantic scope and contrastive controls when future real-user
evidence justifies a repair.

| Family | Invariant / contrast |
|---|---|
| Organization vs person | Resolve the entire bounded entity phrase. A communication verb or capitalization alone does not establish personhood. TD Bank illustrates institutional identity; preserve a genuine person before an `at organization` adjunct. |
| Task/topic vs person | Job Applications illustrates a topic/object phrase, not a personal name. Acquired objects such as contact solution retain their noun role. |
| Quoted/reported operation scope | A command quoted or attributed inside content must not execute as the user's app instruction. Quotation marks, apostrophes and numeric unit marks have distinct roles. |
| Message content vs app command | Sending a message is the outer task; clocks, recurrence, cancellation and alarms inside its body are content. A separately addressed reminder remains independent. |
| Temporal/event scope | A date does not reveal the end time of an unknown event. Restored siblings retain their governing condition and review state. Preserve explicit clocks through calendar corrections. |
| Location trigger ownership | A later location trigger cannot own earlier independent actions or supply their recipient/geofence. Unresolved references stay reviewable. |
| Cancellation target ownership | Bind a withdrawal to its unique in-capture target/group. Preserve independent survivors and inherited context; ambiguous matches cannot execute destructively. Stored matching still needs device validation. |
| Non-actionable thought vs task | Explicit thoughts, facts and memory frames own their imperative/date content. An independently stated task closes that scope. Past modal reflection does not create a current commitment. |

Regression anchors are ActionabilityTests and ThoughtCompletionTests, the
conditional-intent devset, the immutable187 cancellation /72 conditional slices,
and saved Candidate47 affected-family/287-case safety closure outputs. Consult
the source manifest and evidence integrity record before future comparison.
The remaining grouping/date/contact metadata issues are real limitations,
not reasons to add brand names or failed utterances to parser lists.
