# Screen Specifications

## Today

Purpose: answer “What can I act on?”

- Time-aware greeting and current date
- **Now:** overdue items and the next scheduled action
- **Rest of today:** actions scheduled before the day ends
- **Coming up:** collapsed preview of actions scheduled tomorrow or later
- **When you have time:** ready actions with no date, shown by default
- Every time-based section includes a literal explanation of its membership rule
- Persistent capture call to action
- Hide empty sections
- Empty state when no relevant items exist
- Hand Tap toolbar action opens capture-anywhere setup

## Memory

Purpose: answer “What useful knowledge did I save?”

- Search across titles, original words, people, categories, and types
- Default **All** view groups items into Ideas, People, and Notes & context
- Pinned items stay in a dedicated section above automatic groups
- Filter menu narrows to a single automatic group or Archive
- Filter controls stay single-line and horizontally scroll at large text sizes
- Edit affordance on every row
- Archive/restore swipe action
- Capture toolbar action
- Separate empty states for All, Pinned, filtered, search, and Archive views

## Capture

Purpose: speak by default, with typing available in one deliberate action.

- Large breathing memory pulse in the centre
- Pulse expands in response to microphone level while listening
- Live transcription beneath the pulse
- Tap pulse again to finish and save
- **Type instead** transforms the experience into a large text editor
- Recognition failures preserve usable partial text in the typing interface
- Saved state contracts into a checkmark with haptic confirmation
- Permission-denied state offers Settings and typing paths

## Navigation

- Two destinations only: Today and Memory
- A custom floating dock contains the signature waveform capture control
- Capture appears full screen to minimize distraction and prevent accidental navigation while recording
- Warm neutral surfaces, rounded system typography, and one violet accent form the visual language

## Item editor

- Editable structured fields
- Optional due date
- Read-only original capture, timestamp, and source
- Complete/incomplete, archive/restore, and delete actions
- Confirmation before permanent deletion
- Cancel and Save toolbar controls

## Accessibility

- Controls have explicit action-oriented labels and hints.
- Decorative icons are hidden from VoiceOver where appropriate.
- Headings use semantic header traits.
- Dynamic Type is supported through system text styles.
- Meaning is never conveyed only by colour.
